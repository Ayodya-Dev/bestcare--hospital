========================================
4) LOGIN VALIDATIONS (VERY IMPORTANT)
========================================
File: auth/login.php
Also: assets/js/main.js

3 validation layers:

A) HTML validation
   - input has required
   - Browser stops empty submit

B) JavaScript validation (main.js)
   - Checks username and password not empty
   - If empty -> alert + e.preventDefault()

C) PHP validation (server - lecture style)
   - strlen($username) == 0 || strlen($password) == 0
     -> "Need to fill all the fields"
   - Wrong password / user not found
     -> "Wrong username or password"
   - Correct -> password_verify + session + redirect by role

### Say in demo
> "I validate three ways: HTML `required`, JavaScript empty check,
> and PHP `strlen` plus password check with `password_verify`."


========================================
5) SESSION + ROLE REDIRECT
========================================
After login, save:
- $_SESSION['user_id']
- $_SESSION['username']
- $_SESSION['role']

Redirect:
- admin   -> ../admin/dashboard.php
- staff   -> ../staff/dashboard.php
- patient -> ../patient/dashboard.php

File: includes/check_login.php
File: auth/logout.php

### Say in demo
> "After login I save the user in session and open the correct dashboard by role.
> Protected pages use check_login.php. If no session, go back to login.
> Logout uses session_unset and session_destroy."
